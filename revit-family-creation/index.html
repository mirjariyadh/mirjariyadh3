DISCIPLINED EXECUTION

The 5-Step Development Workflow

A transparent, milestone-driven process ensuring every delivered RFA file complies with agreed mechanical specifications and Autodesk best practices.

STEP 01

Drawing & Data Intake

Submit product 2D/3D CAD drawings, submittal sheets, catalog dimension charts, and MEP connector specifications.

STEP 02

Scope & LOD Agreement

Review parameters, LOD requirement (300 or 350), Revit version targeting, and type catalog structure before modeling begins.

STEP 03

Parametric Solid Modeling

Creation of pure native solid geometry, reference planes, parameter formulas, materials, and MEP connectors.

STEP 04

Rigorous QA Testing

Testing the family in actual Revit project environments: flexing all parameters, verifying MEP duct/pipe connections, and checking file size.

STEP 05

Delivery & Handover

Delivery of final clean .RFA files, external type catalog .TXT files, shared parameter files, and technical usage guide.

TECHNICAL DISCIPLINE

Manufacturing Quality Standards

Every family is engineered to prevent project bloat, eliminate Revit error warnings, and provide seamless scheduling for design engineers.

Zero Imported CAD Meshes

Built 100% using native Revit solids, voids, extrusions, and sweeps. Never contains exploded DWG layers, SAT files, or corrupt polymesh data.

Purged Lightweight Files

Target file sizes strictly kept under 800 KB (often <500 KB), ensuring hundreds of instances can be placed in large BIM projects without lag.

Flow-Linked MEP Connectors

Connectors feature correct system classifications (Supply/Return Air, Hydronic, Sanitary) and bidirectional airflow/water flow parameter links.

Standard Classification Coding

Pre-populated with OmniClass Table 23, UniFormat, and MasterFormat codes for automated BIM quantity takeoff and specification schedules.
